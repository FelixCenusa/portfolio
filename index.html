Custom File System with FAT

  • C++

A flexible file system in C++ with its own File Allocation Table. It supports adjustable block sizes and the standard file operations. Drive a re-creation of the allocator: create, copy, move and delete files, and watch the block chains.

Features
  • Adjustable block sizes
  • File and directory commands: ls cd mv cp mkdir create
  • A streamlined FAT design for performance

8-Segment Display Controller

  • ARM assembly

An ARM Assembly program that drives an 8-segment display and counts up or down based on user input. Input comes from the keyboard or physical push buttons, handled with both polling and interrupts. Switch modes in the simulation and watch what the CPU does.

Features
  • Real-time input through polling and interrupts
  • Works with the keyboard and physical push buttons
  • Configurable counting direction, up or down
  • Efficient display refresh
